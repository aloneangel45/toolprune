# Security Policy

## Supported Versions

We release patches and security fixes for the active release series:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is paramount for ToolPrune, especially given its role as an in-line MCP proxy handling sensitive agent communications.

If you discover a security vulnerability within ToolPrune:
1. **Do NOT open a public issue.**
2. Send an email to `security@aloneangel.dev` (or open a confidential GitHub Security Advisory directly on this repository).
3. Include detailed steps to reproduce the issue, proof of concept code, and impacted components.

### Our Response Process
- **Initial Response:** Within 48 hours acknowledging receipt of your report.
- **Triage & Assessment:** Regular updates every 72 hours until a fix is verified.
- **Disclosure:** We will coordinate public disclosure alongside a patched release.
