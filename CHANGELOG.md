## [1.4.1] - 2026-11-21

### Security & Bug Fixes
- **MCP Security Guard & Quarantine Bypass Hardening (`pkg/security/guard.go`, `pkg/security/lockfile.go`, `pkg/proxy/proxy.go`, `pkg/router/router.go`, `cmd/toolprune/proxy.go`)**:
  - Blocked notification-smuggled `tools/call` payloads (missing JSON-RPC `id`, both standalone and inside JSON-RPC 2.0 batches `[...]`) in `Proxy.handleClientNotification` so quarantined or profile-blocked tools can never be invoked via notification forwarding.
  - Re-checked `SecurityGuard.IsQuarantined` and `ToolFilterFunc` after `DynamicCatalog.InterceptCall` unwraps `toolprune_invoke` in wrapper mode, and attached `SecurityGuard` to multi-upstream `Router` (`AttachSecurityGuard`) to enforce quarantine across `PreValidateCall`, `RouteToolCall`, `toolprune_invoke`, and JSON-RPC 2.0 batches with per-upstream isolation.
  - Normalized prefixed (`server__tool`) vs unprefixed (`tool`) lookups in `Guard.IsQuarantined`, `Guard.IsQuarantinedAnyUpstream`, and `Lockfile.Verify` so namespace mismatches never bypass quarantine or cause false lockfile drift.
  - Closed tool-poisoning scanner bypasses: added two-pass HTML entity decoding (`&#x3c;IMPORTANT&#x3e;`, `&lt;SYSTEM&gt;`, `&amp;lt;...&amp;gt;`) and concealed-Unicode stripping before regex evaluation, broadened tag/bracket rules for attributes and whitespace (`<IMPORTANT priority="high">`, `[ SYSTEM ]`, `[/INST]`), increased recursive schema depth to 64, and extended scanning to map property keys, arbitrary string fields (`x-instructions`, etc.), `[]string`/`[]map[string]any` slices, `required`, `dependentRequired`, and `icons`.
  - Closed SHA-256 rug-pull hash blind spot by including `title`, `outputSchema`, and `annotations` (`omitempty`) in `ComputeToolHash`; added `fsync` before close in atomic `SaveLockfile` writes and `Guard.Close`, enforced `0600` permissions on pre-existing `--security-log` files on POSIX, added `TOOLPRUNE_LOCKFILE` env support, and fixed a signal-handler goroutine leak in `runProxy`.
- **Tool Output / Response Pruner Hardening (`pkg/pruner/response.go`)**:
  - Fixed a multi-byte UTF-8 rune-vs-byte budget bug in `truncateHeadTail` where 3/4-byte strings (CJK, emojis) could bypass truncation or exceed tiny budgets (`--max-response-tokens 20`), replacing rune-count guessing with exact `utf8.RuneLen` byte accumulation so output is always valid UTF-8 and strictly within budget (with 70/30 head-weighted preservation for `isError: true` headers).
  - Upgraded `pruneJSONObjectArrays` to recursively compact large arrays nested inside arbitrary JSON object/array hierarchies (e.g., `{"data": {"items": [...]}}`) while preserving valid JSON and keeping compacted summaries when `k=1` still exceeds budget.
- **Live Telemetry & `toolprune top` Hardening (`pkg/metrics/telemetry.go`, `cmd/toolprune/top.go`)**:
  - Replaced Go `%q` label formatting in `RenderPrometheus` with strict Prometheus 0.0.4 escaping (`\` -> `\\`, `"` -> `\"`, `\n` -> `\n`) so tabs and non-ASCII UTF-8 upstream IDs never emit invalid `\t`/`\u` escape sequences.
  - Configured `ReadHeaderTimeout`, `ReadTimeout`, `WriteTimeout`, and `IdleTimeout` on the `--metrics-addr` HTTP server, and guarded `SetPricePerMillionTokens` and computed snapshot floats against `NaN`, `±Inf`, and division-by-zero.
  - Hardened `toolprune top` with URL scheme/host validation, 4 MiB body cap, strict JSON object checks (rejecting `null`/non-objects), nil-context safety, and uptime overflow guards.
- **`toolprune audit` Secret Redaction & SARIF 2.1.0 URI Normalization (`cmd/toolprune/audit.go`, `pkg/security/guard.go`, `pkg/security/sarif.go`)**:
  - Hardened `redactSecret` (`[REDACTED]` for `<= 12` runes, 3-char prefix + `****[REDACTED]` for longer secrets), sanitized credentials/tokens in CLI `args` and HTTP `url` evidence, and audited IDE `headers` maps (while allowing `Bearer ${ENV_VAR}` placeholders) so raw secrets never leak into table, JSON, or SARIF output.
  - Added cross-platform `NormalizeSARIFURI` emitting RFC 3986 / SARIF 2.1.0 `file:///` URIs for Windows drive paths (`C:\...`), UNC paths (`\\server\...`), and POSIX absolute paths with proper percent-encoding, and stripped UTF-8 BOM in `--schema-file` loading.

## [1.4.0] - 2026-11-21

### Added
- **MCP Tool-Poisoning Guard & SHA-256 Rug-Pull Lockfile (`pkg/security`, `pkg/proxy`, `pkg/config`)**:
  - Added static and runtime tool-poisoning scanner inspecting MCP tool `name`, `title`, `description`, and nested JSON Schema descriptions for hidden prompt-injection tags & stealth directives (`<IMPORTANT>`, `<SYSTEM>`, `ignore previous instructions`, `disregard prior`, `you must first`, `before calling this tool`, `do not mention to the user`, `silently`), sensitive path exfiltration targets (`~/.ssh`, `id_rsa`, `~/.aws`, `.env`, `/etc/passwd`, `credentials.json`), concealed zero-width/BiDi Unicode spoofing (`U+200B..U+200F`, `U+202A..U+202E`, `U+2066..U+2069`), large embedded Base64 blobs, and shell command smuggling patterns.
  - Added canonical SHA-256 rug-pull lockfile (`toolprune.lock`) pinning `(name, description, inputSchema)` per upstream server with `off`, `warn`, `enforce`, and `update` modes (`--security-mode`, `--lockfile`, `security:` in `toolprune.yaml`). In `enforce` mode, ToolPrune quarantines tools that mutate mid-session, drift from `toolprune.lock`, or trigger high/critical poisoning rules and blocks direct `tools/call` execution against quarantined tools.
  - Added structured MCPGate-compatible JSONL security event logging (`--security-log <path>`, `security.security_log`).
- **`toolprune audit` Security Subcommand & SARIF 2.1.0 Export (`cmd/toolprune/audit.go`, `pkg/security/sarif.go`)**:
  - Audits `toolprune.yaml` (`-c`), static JSON tool schema files (`--schema-file`, supporting both `[]Tool` and `{"tools": [...]}`), and host IDE MCP configs (`--all-ides` across Claude Desktop, Claude Code, Cursor, VS Code, Windsurf, and Zed — flagging unpinned `npx`/`uvx` commands, hardcoded secrets in `env` with redacted evidence, and insecure non-loopback `http://` remote URLs).
  - Supports `--format table|json|sarif` (OASIS SARIF 2.1.0), `--fail-on critical|high|medium|low` CI exit gating, and `--lockfile` / `--update-lockfile`.
  - Integrated `security` and `response_pruning` configuration diagnostics into `toolprune doctor` (`pkg/doctor`).
- **Deterministic Tool Output / Response Pruner (`pkg/pruner/response.go`, `pkg/proxy`, `pkg/router`, `pkg/config`)**:
  - Added `ResponsePruningConfig` (`max_response_tokens`, `preserve_errors`, `array_head_tail`, `deduplicate_logs`) and `--max-response-tokens <N>` / `TOOLPRUNE_MAX_RESPONSE_TOKENS` on `toolprune proxy`.
  - Intercepts `tools/call` responses in both wrapper and multi-upstream gateway modes: preserves `isError: true` error messages intact (only trimming massive non-essential tails when grossly over budget), compacts JSON arrays to head+tail `K` items with deterministic `[... N items omitted by ToolPrune ...]` summary markers, deduplicates consecutive identical/near-identical log lines as `(repeated Nx)`, and enforces deterministic UTF-8 rune-safe head+tail truncation within the token ceiling.
- **Live Token & Latency Telemetry + `toolprune top` Dashboard (`pkg/metrics`, `cmd/toolprune/top.go`)**:
  - Added thread-safe per-upstream telemetry tracking `requests`, `errors`, `schema_tokens_raw`, `schema_tokens_pruned`, `response_tokens_raw`, `response_tokens_pruned`, `security_alerts`, `avg_latency_ms`, and estimated USD saved.
  - Added `--metrics-addr <host:port>` (`server.metrics_addr`, `TOOLPRUNE_METRICS_ADDR`) on `toolprune proxy` serving Prometheus text exposition at `/metrics`, structured JSON at `/api/stats`, and `/healthz`.
  - Added `toolprune top [--url http://127.0.0.1:9095/api/stats] [--once] [--interval 1s]` live terminal telemetry dashboard.

## [1.3.2] - 2026-11-15

### Fixed
- **MCP Multiplexer Upstream Requests & Deterministic Collision Detection (`pkg/router/multiplex.go`, `pkg/router/gateway.go`, `pkg/proxy/proxy.go`, `pkg/config/config.go`)**: Handled upstream-to-client JSON-RPC requests (`roots/list`, `sampling/createMessage`, `ping`) in `Multiplexer.runUpstreamLoop`, `RouterGateway`, and `Proxy` by forwarding to an active client with reverse request correlation or returning `-32601 Method not found` so upstreams never block indefinitely; sorted upstream IDs and tool names in `rebuildRoutesUnderLock()` to detect collisions deterministically (`ErrToolCollision`) instead of random Go map overwrite; and rejected duplicate effective upstream `Prefix` values in `Config.Validate()` when prefix namespacing is active.
- **Streamable HTTP Error Propagation, Session Lifecycle & CORS/Host Hardening (`pkg/proxy/sse.go`, `pkg/proxy/session.go`, `pkg/router/gateway.go`)**: Propagated `HandleClientMessage` errors on `POST /mcp` as immediate `-32603` JSON-RPC error responses so `<-capture.respCh` never hangs; avoided registering stateless `POST /mcp` sessions as persistent push clients and unregistered SSE/Streamable HTTP stream clients on `r.Context().Done()`; added `SessionManager` idle TTL eviction and `MaxSessions` bounds; made `SSESession.Send` non-blocking on full buffers and snapshotted client slices before releasing `clientsMu.RLock()`; and hardened loopback host validation (`net.ParseIP(h).IsLoopback()` across `127.0.0.0/8` + `localhost.`) and wildcard `"*"` CORS headers (never reflecting arbitrary `Origin` or `Access-Control-Allow-Credentials`).
- **JSON-RPC 2.0 Batch Support Across Stdio & HTTP/SSE (`pkg/proxy/batch.go`, `pkg/proxy/stdio.go`, `pkg/proxy/sse.go`, `cmd/toolprune/proxy.go`)**: Added full JSON-RPC 2.0 batch array `[...]` parsing and concurrent ordered dispatch over stdio, `POST /mcp`, and `POST /messages` (returning `-32600 Invalid Request` on empty `[]`, per-element `-32600` on invalid entries, and omitting notification-only responses).
- **Subprocess Supervision Cleanup, YAML Env Expansion & Meta-Tool Controls (`pkg/proxy/supervisor*.go`, `pkg/config/loader.go`, `pkg/router/router.go`, `pkg/router/catalog.go`)**: Made `cleanupPlatformSupervision` idempotent and invoked it in the natural child-exit waiter goroutine so Win32 Job Object handles never leak, and added a `stopPoll` signal in `supervisor_unix.go` so `-pgid` polling goroutines exit promptly; expanded `${VAR}` on parsed `yaml.Node` scalar values so Windows backslashes (`C:\Users\...`) and `#` characters inside environment variables never corrupt YAML parsing; and honored `CatalogConfig.EnableMetaTools` and individual `Enable*Meta` flags across `Router` and `GetMetaToolDefinitions`.
- **Installer Line-Ending Enforcement, Restricted `install.ps1` & GitHub Actions Node 24 (`install.sh`, `install.ps1`, `.gitattributes`, `.github/workflows/*.yml`)**: Added `.gitattributes` enforcing LF on `.sh`/`.go`/`.yml` and CRLF on `.ps1`; converted `install.sh` to pure LF with `mkdir -p "${INSTALL_DIR}"` in both root and non-root paths and atomic temp-file + `mv -f` installation; hardened `install.ps1` inside `Install-ToolPrune` using `throw`, pure `.NET` I/O, additive TLS 1.2, `System.IO.Compression.FileSystem` assembly loading, and `ReadOnly` attribute clearing so empty or `pwsh`-7-polluted `PSModulePath` and `irm | iex` sessions succeed cleanly; and enabled `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: "true"` in `ci.yml` and `release.yml`.

## [1.3.1] - 2026-11-14

### Fixed
- **JSONC & UTF-8 BOM Support for Zed, VS Code & Client Configs (`pkg/preset`, `pkg/doctor`, `cmd/toolprune`)**: Implemented a string-aware `NormalizeJSONC` scanner that strips UTF-8 BOM headers, `//` line comments, closed `/* ... */` block comments, and trailing commas before `}` or `]` without altering `//`, `/*`, escaped quotes, or `,}` sequences inside JSON string literals (while leaving unterminated block comments and double commas invalid). Integrated across `preset.ConfigFile.UnmarshalJSON`, `preset.MergeInto` (including comment-only Zed `settings.json` files), `preset.Validate` / `ValidateForClient` / `ValidateFile`, `doctor` client config inspection, and `toolprune config patch-claude`.
- **Restricted PowerShell Compatibility in `install.ps1` (`install.ps1`)**: Replaced `Get-FileHash` and `Expand-Archive` (which fail with `CommandNotFoundException` in stripped/non-autoload `PSModulePath` PowerShell sessions) with built-in `.NET` `[System.Security.Cryptography.SHA256]::Create()` over a disposed file stream and `[System.IO.Compression.ZipFile]::ExtractToDirectory`, extracted into a dedicated subdirectory, and hardened User `PATH` deduplication against empty `PATH` values and substring false matches.
- **`SSEClientTransport` Goroutine Leak, Short Startup Context & Channel Race (`pkg/proxy/sse_client.go`, `pkg/proxy/sse.go`)**: Replaced the leaked context-watcher goroutine in `SSEClientTransport.Start` with `context.AfterFunc` + `defer stopWatch()` so POST-first Streamable HTTP (`405 Method Not Allowed`) and connection errors leak zero goroutines and cancelling a short-lived handshake context after `Start` succeeds no longer kills the live `/sse` stream; synchronized `enqueueMessage` and `closeRecvChannel` under an `RWMutex` + shutdown signal to eliminate `send on closed channel` panics under concurrent `Send`/`Close`; closed pooled HTTP idle sockets on `Close()`; rejected hostless `http://` URLs; fixed `ExtractHTTPHeadersFromEnv` key slicing when env keys have surrounding whitespace or multibyte characters; and ensured `SSEServer.Shutdown` tears down sessions even in handler-only mode.
- **StreamFilter Pre-Binding Validation Clobbering, Cache Collisions & Schema Semantics (`pkg/proxy/stream_filter.go`, `pkg/proxy/proxy.go`, `pkg/router/router.go`)**: Added `FilterProjectedToolsList` so combining Tier 4 dynamic catalog projection with `--max-schema-tokens` no longer overwrites cached raw `InputSchema` definitions with empty stubs; upgraded `fingerprintToolsRequest` to hash full recursive schema structures (property names, types, enums, combinators, `required`, `additionalProperties`, and pinned tools) and deep-cloned cached `[]mcp.Tool` slices to prevent stale cache hits and caller-mutation aliasing; fixed `ValidateToolArguments` so `oneOf` rejects values matching multiple branches (`matches > 1`), `required` properties whose schemas explicitly allow `null` accept `null`, and local `$ref` pointers unescape RFC 6901 `~1`/`~0` tokens.
- **Cross-Platform Path Handling, Atomic Config Writes & Nil Guards (`pkg/preset`, `pkg/proxy`, `pkg/router`, `cmd/toolprune`, `cmd/preset`)**: Normalized Windows `\` and POSIX `/` path segments in `preset.inferClientFromPath`, `config patch-claude` (`doctor.IsToolpruneBinary` to prevent double-wrapping Windows `toolprune.exe` paths on Unix), and wrapper upstream ID generation; added `--mode` validation and atomic temp-file + rename writes to `config patch-claude` and `preset.WriteFile`; guarded nil upstream/session dereferences in `Proxy` (`handleClientNotification`, `handleClientResponse`, `runUpstreamLoop`, `RegisterClient`) and `RouterGateway.RegisterClient`; switched `preset generate --env` to `StringArrayVar` so comma-containing env values are not split; and fixed CLI flag reset hygiene across `version`, `config`, and `TOOLPRUNE_*` env fallbacks.
- **Catalog Rune Truncation & Markdown Link Stripping (`pkg/router/catalog.go`, `pkg/pruner/params.go`)**: Guarded `CleanSummaryDescription` against `maxLen <= 0` slice-bounds panics, computed word-boundary truncation in rune indices rather than byte offsets for multi-byte UTF-8 text, stripped multi-hash markdown headings (`###`), and rewrote `stripMarkdownLinks` as a single-pass linear scanner so preceding non-link brackets such as `[NOTE]` no longer abort link stripping.

## [1.2.0] - 2026-11-10

### Added
- **RFC #1 Progressive Token-Budget Compactor (`pkg/pruner/budget.go`)**: Sub-0.5ms 5-pass AST compactor (`--max-schema-tokens=N`, `TOOLPRUNE_MAX_SCHEMA_TOKENS`, `pruning.max_schema_tokens`) that strictly retains JSON Schema types, `properties`, `required`, `enum`, `const`, `items`, `$ref`, reachable `$defs`/`definitions`, `anyOf`/`oneOf`/`allOf`, numeric/array bounds, and `additionalProperties` while progressively compacting leaf docstrings and projecting overflow cold tools via `ProjectCompactTool`.
- **Adaptive JSON-RPC Stream Filter (`pkg/proxy/stream_filter.go`)**: Lock-guarded `<5us` call-context recency and domain-prefix affinity tracker, FNV-1a fast-path `tools/list` projection cache (`<0.05ms` cache hit), and `<0.1ms` recursive pre-binding `tools/call` validator returning self-correcting `CallToolResult{IsError: true}` diagnostics before forwarding invalid calls upstream.
- **Multi-Upstream Gateway & MCP Streamable HTTP (`pkg/router/gateway.go`, `pkg/proxy/sse.go`, `pkg/proxy/sse_client.go`)**: Full asynchronous multi-upstream routing over stdio, classic SSE (`GET /sse` + `POST /messages`), and MCP Streamable HTTP (`POST/GET/DELETE /mcp` with `Mcp-Session-Id`), plus outbound `SSEClientTransport` for remote `transport: "sse"` upstreams, paginated `NextCursor` handshakes, and all four dynamic meta-tools (`toolprune_search_tools`, `toolprune_get_tool_schema`, `toolprune_activate_tools`, `toolprune_invoke`) in both gateway and single-upstream wrapper modes.
- **Complete CLI & Preset Workflows**: `--preset` (`fast|balanced|strict|dynamic`), `--stats`, `--profile`, `--namespace` on `toolprune proxy`; `--format csv`, `--verbose` per-parameter breakdown, `--max-schema-tokens`, and live subprocess benchmarking (`toolprune bench -- <cmd>`) on `toolprune bench`; real `--profile` and `--filter` evaluation in `toolprune routes`; and `toolprune config patch-claude` with `--dry-run` and `.bak` backup protection.
- **Realistic Enterprise MCP Benchmark Suite (`pkg/benchmark/suites.go`, `test/fixtures/mcp_suite_realistic.json`)**: Verbose PostgreSQL DDL migration, Filesystem multi-hunk diff, and GitHub AST schemas achieving up to 96.5% token reduction (`cl100k_base`) and `<0.5ms` stream compaction latency.

### Fixed
- **Full JSON Schema & Modern MCP Fidelity**: Preserved `$defs`, `definitions`, `anyOf`, `oneOf`, `allOf`, `not`, `patternProperties`, `dependentSchemas`, `dependentRequired`, `minProperties`, and `maxProperties` on `mcp.InputSchema`, plus `title`, `outputSchema`, `annotations` (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`, `title`), and `icons` on `mcp.Tool`.
- **UTF-8 Rune Safety & Structural Cloning**: Eliminated slice bounds panics and multi-byte UTF-8 truncation corruption across `params.go`, `condense.go`, `catalog.go`, and `benchmark/table.go`; replaced JSON round-trip cloning in `DeepCopyTools` with direct structural Go cloning.
- **Bounded Framing, Supervisor Drain & Concurrency Races**: Replaced unbounded `ReadBytes`/`ReadString` with `ReadBoundedLine` (`64 KiB` initial buffer, `10 MiB` pre-allocation hard cap); drained `stdoutPipe`/`stderrPipe` completely prior to `cmd.Wait()` in `Supervisor`; resolved data races in `Proxy.SetPruner`, `benchmark.ResetEncoder`, and `Multiplexer.SetMessageHandler`; and added non-crashing JSON-RPC `-32700`/`-32600` recovery for malformed JSON and batch arrays on stdio.
- **Localhost HTTP Security & Namespaced Profiles**: Enforced localhost `Host` and `Origin` validation on `SSEServer` to block DNS-rebinding and cross-origin browser attacks, echoed single matched CORS origins with `Vary: Origin`, enforced `Filter.IsAllowed` inside meta-tools, and added `*__get_*`, `*__list_*`, `*__read_*`, `*__search_*`, and `*__fetch_*` to `ProfileMinimal`.
- **Installers & CI/CD Pipeline**: Fixed `$Arch` archive naming in `install.ps1`, added `checksums.txt` SHA-256 verification to `install.sh` and `install.ps1`, added `-race` testing on Linux/macOS in `ci.yml`, added `windows/arm64` + pre-release test gate in `release.yml`, and injected version `-X` ldflags in `Dockerfile`.
